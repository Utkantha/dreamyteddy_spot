📁 IMAGES FOLDER
================

Place your teddy bear photos here!

HOW TO USE:
1. Save your teddy bear images in this folder
2. Name them: teddy1.jpg, teddy2.jpg, teddy3.jpg, etc.
3. Update the image paths in script.js

EXAMPLE:
- teddy1.jpg → for "Cloudy the Dreamer"
- teddy2.jpg → for "Starry Night Bear"
- teddy3.jpg → for "Honey Hug Bear"
... and so on for all 12 products

IMAGE REQUIREMENTS:
- Format: JPG, PNG, or WebP
- Size: 600x600 pixels or larger (square works best)
- File size: Under 500KB recommended

WHERE TO GET FREE IMAGES:
- Pixabay: https://pixabay.com/images/search/teddy%20bear/
- Unsplash: https://unsplash.com/s/photos/teddy-bear
- Pexels: https://www.pexels.com/search/teddy%20bear/

For detailed instructions, see HOW_TO_ADD_IMAGES.md in the main folder.
